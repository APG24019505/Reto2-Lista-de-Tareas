# Mi App Web – Lista de Tareas

Aplicación sencilla para gestionar tareas pendientes, desarrollada con HTML, CSS y JavaScript.

 Tecnologías

- HTML5
- CSS3 (minificado con cssnano)
- JavaScript (minificado con terser)

 Optimizaciones aplicadas

- Minificación de CSS y JS.
- Compresión de imágenes a WebP.
- Uso de `loading="lazy"` en imágenes.

 Empaquetado
El proyecto se empaquetó en un archivo `to_do_list.tar.gz` para su despliegue.

 Cómo usar
Abre `index.html` en tu navegador o accede a través del servidor local configurado
